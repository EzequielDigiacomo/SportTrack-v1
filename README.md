# SportTrack Backend - .NET 8

Sistema de gestión deportiva avanzada para eventos de remo y canotaje.

## Documentación
Para comprender cómo está estructurado el proyecto, las capas y los patrones de diseño utilizados, consulta:
👉 [Documentación de Arquitectura](docs/ARCHITECTURE.md)

## Requisitos
- .NET 8 SDK
- PostgreSQL
- Entity Framework Core CLI (`dotnet ef`)

## Configuración Rápida
1. Configura tu cadena de conexión en `appsettings.json`.
2. Ejecuta las migraciones: `dotnet ef database update`.
3. Ejecuta el proyecto.
